Worker configuration

The configuration file controls how the worker connects to the queue and how many jobs it runs at once.

Options

OptionDefaultMeaning
concurrency4Jobs processed in parallel
timeout30Seconds before a job is cancelled

Example

worker:
  concurrency: 8
  timeout: 60

Restart the worker after changing the file, because settings are read only at startup.
